# Release notes

## 1.0.0 — production build

- Native conversion for 3D, CAD, vector, image/RAW, PDF, documents, audio, video and archives. Conversion files are processed on-device and never uploaded.
- Interactive 3D Studio with orbit/pinch, clay/color/wire rendering, print-readiness checks and offline turntable GIF export.
- Content-first Smart Format Detection with mismatch warnings.
- Mixed-family batch queue with per-file smart targets, presets, live progress, cancellation and retry.
- Quality recipes for image edge/quality, audio bitrate, video size/bitrate, GIF size/fps, PDF page and archive compression.
- Conversion X-ray reports with verification, checksum, pipeline and warnings.
- Private vault with search, family filters, thumbnails, preview, rename, delete, share, Save copy to Downloads and folder browsing.
- Android share-sheet intake and output; drag-and-drop drop target.
- New ink-and-ember adaptive icon, branded splash, and a three-page first-run tour.
- Theme system: System, Light and Dark, four accent colours (Ember, Sage, Gold, Cobalt) and OLED-friendly pure-black mode.
- Rebuilt Settings: theme previews, default recipe, Downloads copy, auto-open queue, keep-screen-awake, notification shortcut, vault/history clearing with confirmation, privacy summary, replay welcome tour.
- Optional Google AdMob banner, frequency-capped interstitial and opt-in rewarded ad that unlocks 24 hours ad-free. The banner is placed above the app navigation and never covers Android's system buttons.
- One-time Remove Ads purchase (US$4.99 / local Play price) with Restore purchase. Ad consent and privacy options use Google UMP where required.

Known limits: codec-dependent HEIC/AVIF/audio/video targets are hidden when unsupported; DNG uses its embedded preview; 3D textures are not carried between formats; no PDF OCR, STEP/IGES, RAR or password-protected archives in 1.0. See README and the in-app Format guide. Production requires the owner's AdMob IDs, UMP message, `remove_ads` Play product and Play licensing key.
